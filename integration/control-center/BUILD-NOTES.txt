Refresh command (all paths explicit, no device access):
python integration/control-center/refresh_payload.py \
  --base-apk /path/to/verified-installed-v02-control-center.apk \
  --helper-dex /path/to/reviewed/classes.dex \
  --java /path/to/java \
  --build-tools /path/to/android-sdk/build-tools/35.0.0 \
  --signing-key /external/platform.pk8 \
  --signing-cert /external/platform.x509.pem \

  --work-dir /absolute/new-nonexistent-output-directory
The output directory parent must already exist. It must not contain or
alias inputs, tools, dependencies or signing files. Outputs are
control-center-underclock-signed.apk, signature-verification.txt and
refresh-verification.json. Publication is atomic and never overwrites an
existing final path. The default refresh requires the exact 23 original
helper classes. For v0.3.0, add --custom-profiles: this requires exactly the
47 reviewed Custom helper classes, including the shared editor, validated
values/commands, transactional slot store, and D8 35.0.0 lambda classes.
Arbitrary additions remain rejected. Runtime's public static boot(Context)
and install(View) entrypoints remain required.
Run tests/test_refresh_payload.py for the host protection-boundary tests.

v0.3.0 helper compilation (JDK21, SDK36, D8/build-tools35.0.0):
- Compile integration/control-center/*.java AND shared/*.java together with
  javac -encoding UTF-8 -source 8 -target 8, using SDK36 android.jar as classpath.
- Jar the resulting com/anbernic/control/underclock class tree, then run
  com.android.tools.r8.D8 from build-tools35.0.0/lib/d8.jar with --min-api 26
  and --lib pointing to SDK36 android.jar. Keep its single classes.dex.
- Run the pinned refresh command above with --custom-profiles.
- Copy its verified signed APK to app/build/generated/controlcenter/control-center.apk
  before running assembleDebug, testDebugUnitTest and lintDebug. Do not run
  clean after copying the payload. Gradle also includes the shared Java sources
  in the standalone application; no vendor classes enter the frontend DEX.
- v0.3.0's debug build uses the original application ID to update the user's
  v0.2 installation. Retain the matching external frontend signing keystore
  when building an update. A fresh local debug key cannot update an APK signed
  by another machine. Signing files must never enter source or source ZIPs.

This helper reconstructs a patch of the user's own stock Control Center APK.
It never connects to a device or installs a package. The release's standalone
underclock app performs the separately guarded Shizuku installation.

--helper-dex can be repeated if D8 emits multiple helper DEX files.
--python-deps DIRECTORY is optional for an already installed, isolated Python
dependency tree. Without it, the normal Python environment must supply
androguard. --work-dir is optional and defaults to a new OS temporary folder.
Choose an external work directory so generated APKs, decoded vendor smali,
original method snapshots and signing diagnostics remain outside tracked source.
The script does not download a vendor APK, SDK, signing key or tool.

Verified transformation:
- Apktool decode -r keeps AndroidManifest.xml and resources.arsc raw.
- The active right-edge performance panel is Lu0/A, a ScrollView created by
  the Control Center panel factory. Its constructor moves content out of the
  binding FrameLayout, so the hook passes the live p0 ScrollView directly to
  UnderclockRuntime.install(View) before the constructor's final return.
- ControlCenterService.onCreate calls UnderclockRuntime.boot(Context) directly
  after the original Service.onCreate call. No register allocation is increased.
- Exactly two stock methods receive one invoke-static each. The other 29,743
  methods retain identical decoded executable instructions. Original class
  fields, interfaces, superclasses and method inventories are retained.
- The ZIP is composed from the original APK: only stock DEX and signing files
  are replaced, then approved helper DEX is added. All 1,013 original noncode
  entries, including every resource, asset, native library and the complete
  manifest, must remain byte-identical.
- Helper classes must all stay within com.anbernic.control.underclock and
  must not duplicate original classes.
- zipalign verifies 16 KiB native alignment. Signing requests v1/v2/v3;
  apksigner verifies the resulting APK using its v2/v3 schemes on this firmware.
  Package identity, versionCode 9, system shared UID and the exact
  original certificate are rechecked. No new exported component or permission
  is introduced, because the original binary manifest is unchanged.
