# RG477V Under-clock V1.00

RG477V의 순정 Control Center에서 CPU·GPU 상한을 요청하고 Custom 프로필과 FPS/W 표시를 사용하는 비공식 도구입니다.

**[V1.00 APK 다운로드](https://github.com/Breeder1229/rg477v-underclock-public/releases/download/V1.00/rg477v-underclock-V1.00.apk) · [처음 설치하기](docs/INSTALL.ko.md) · [복구 방법](docs/RESTORE.ko.md) · [알려진 한계](docs/LIMITATIONS.ko.md)**

V1.00은 v0.5.1을 바탕으로 안내와 공개 자료를 정리한 첫 공개 배포판입니다. 앱 버전은1.00/versionCode25이며 Control Center 실행부·프로필·팬·열제어 코드는 v0.5.1과 같습니다. 새 성능 최적화나 검증 기기 확대를 뜻하지 않습니다.

## 지원 환경

실기 확인은 **RG477V 8GB 한 대**에서 진행했습니다. Android14, 내부 빌드 **V654202605290319**, Control Center **1.0.29/versionCode9**와 정확한 서명·APK 검사를 모두 통과해야 합니다. v1.39라는 표시만으로 호환을 보장하지 않습니다. Control Center1.0.28은 제조사 정식1.0.29 업데이트가 먼저 필요합니다.

RG477V12GB·RG477M·RG557·GammaOS·다른 펌웨어는 미검증입니다. 모델 이름이나 칩셋이 같다고 지원하는 것은 아닙니다. 호환성 검사를 우회하지 마세요.

## 설치와 사용

1. 위의 **APK 한 개**를 기기에 받습니다. 소스 ZIP과 검증 JSON은 설치 파일이 아닙니다.
2. 파일 앱에서 APK를 열어 설치합니다. v0.5.0/v0.5.1 사용자는 앱을 삭제하지 않고 업데이트합니다.
3. 앱을 열어 **Under-clock 설치** 또는 **Under-clock 연결 확인**을 누릅니다. 첫 실행 자체는 Control Center를 교체하지 않습니다.
4. 상단 빠른 설정의 **Control Center → 사용**을 확인합니다.
5. 오른쪽 가장자리를 왼쪽으로 쓸어 **Perf Mode와 Fan 사이 Under-clock**을 엽니다.

지원 환경에서는 Shizuku·루트·PC·개발자 옵션 없이 설치와 조절, 순정 복구를 사용할 수 있습니다. 앱은 플랫폼 서명과 시스템 UID1000을 사용하므로 일반 앱보다 권한이 큽니다. [설치·권한 설명](docs/INSTALL.ko.md)을 읽어 주세요.

Default / Small / Medium / Large와 Custom1~4를 선택할 수 있습니다. Custom은 CPU 세 그룹·GPU 슬라이더를 조절한 뒤 **저장 및 적용**을 눌러야 합니다. 팬 변경은 Under-clock 선택을 해제하지 않습니다.

앱을 닫거나 강제 종료해도 Control Center가 저장값과 요청 갱신을 담당합니다. 앱 삭제만으로 수정본과 메뉴가 없어지지는 않습니다. 완전히 되돌리려면 삭제 전에 앱의 **순정 Control Center로 복구**를 실행하세요.

## 프로필 참고값

단위는 MHz이며 최대 클럭 요청입니다. 부하와 순정 OS 제어에 따라 실제 클럭은 달라집니다.

| 프로필 | 저전력 ×4 | 성능 ×3 | 최고성능 ×1 | GPU |
|---|---:|---:|---:|---:|
| 순정 최대값 | 2,200 | 3,200 | 3,350 | 1,400 |
| Default | 자체 요청 해제 | 자체 요청 해제 | 자체 요청 해제 | 자체 요청 해제 |
| Small | 2,000 | 3,000 | 3,100 | 1,190 |
| Medium | 1,800 | 2,700 | 2,790 | 1,029 |
| Large | 900 | 1,200 | 1,400 | 601 |

Medium CPU의 대응 지원 단계는1800/2660/2700MHz입니다. 표의 요청값과 실제 지원 단계는 구분합니다. Custom 하한은 CPU700/1000/1100MHz·GPU403MHz, 상한은 순정 최대값이며 지원 단계만 고릅니다. 팬별 별도 프로필 세트는 없고 현재 값은 팬 Bal 측정에서 출발했습니다.

**CPU/GPU 실제 상한의 지속 강제는 아직 검증되지 않았습니다.** 앞선 v0.5.0에서 Medium 요청보다 높은 CPU 표본을 관측했습니다. 저장·요청·응답 확인을 실제 하드웨어 상한 보장으로 해석하지 마세요. 순정 열 보호와 성능 모드는 계속 작동합니다.

## FPS/W 표시

Under-clock 제목 오른쪽, Large 열 바로 위 **FPS/W**를 켜면 좌측 상단에 BAT W·FPS·FPS/W를 표시합니다. 초기값은 OFF입니다.

- BAT의 음수는 방전, 양수는 배터리 순충전입니다. 미보정 전류×전압 추정치이며 CPU/GPU만의 소비전력이 아닙니다.
- FPS는 전면 앱의 단일 SurfaceView 표시 프레임입니다. 에뮬레이터 내부 논리 FPS와 다를 수 있습니다.
- FPS/W는 충전 분리·방전 상태에서만 계산합니다. 미지원 앱이나 모호한 Surface에서는 —로 표시합니다.

[표시값의 정의와 한계](docs/OSD.ko.md)를 참고하세요. 평균·누적Wh·차트·사용 기록은 제공하지 않습니다.

[기존 WLE 결과표](docs/PERFORMANCE.ko.md)는2026-10-15 측정 자료이며 V1.00을 새로 측정한 결과가 아닙니다. 전력 센서와 배터리 잔량 감소의 불일치는 미해결입니다. 절대 소비전력이나 절감률을 확정하는 자료로 사용하지 마세요.

V1.00의 빌드·검사 결과는 [검증 요약](docs/VERIFICATION.ko.md)과 릴리즈 첨부 검증 JSON에 구분해 기록합니다. 기존 v0.5.1 실기 검증은 RG477V8GB 한 대의 기능 시험이며 모든 게임·장시간 안정성을 보장하지 않습니다.
