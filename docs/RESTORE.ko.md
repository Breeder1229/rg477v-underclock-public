# 순정 Control Center로 복구

1. Under-clock 앱에서 **순정 Control Center로 복구**를 누르고 확인창의 **복구**를 선택합니다.
2. 요청 해제와 순정1.0.29 교체, 잔여 요청 만료 대기31초가 끝날 때까지 앱을 열어 둡니다.
3. **순정 Control Center · 자동 재설치 중지** 상태와 가장자리 패널에서 Under-clock 메뉴가 사라졌는지 확인합니다.
4. 더 사용하지 않을 때는 이 확인 후 별도 Under-clock 앱을 삭제합니다.

Custom 네 슬롯과 팬·Perf Mode 등 기존 데이터는 보존합니다. 순정에서는 Custom을 사용하지 않습니다. 다른 앱의 클럭 요청을 해제하는 기능은 아닙니다.

복구 후 앱 재실행·재부팅으로 수정본을 자동 설치하지 않습니다. 다시 사용하려면 **Under-clock 다시 설치**를 직접 누릅니다. 복구 실패·시간 초과도 자동 재설치를 차단합니다. 오류 문구와 환경을 확인하고 복구를 다시 시도하거나 명시적으로 재설치를 선택하세요.

**Default는 이 도구의 요청만 해제하고 메뉴는 남깁니다. 앱 삭제만으로 Control Center가 순정이 되지는 않습니다.** Control Center 데이터 전체 삭제나 임의 APK 교체는 안내하지 않습니다.

앱이 열리지 않거나 설치/복구가 실패하면 개인 정보가 없는 오류 문구와 펌웨어·Control Center 버전을 Issues에 알려 주세요. 호환성·서명 검사를 우회하지 않습니다.
