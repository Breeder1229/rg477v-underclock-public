# V1.00 검증 범위

V1.00은 v0.5.1 기반 공개 배포판입니다. 앱 버전1.00/versionCode25, 화면 제목과 포함 안내를 정리했습니다. Control Center 수정본과 복구용 순정본은 기존 검증 파일과 바이트 단위로 같습니다. 클럭·프로필·팬·열제어 정책은 변경하지 않았습니다.

V1.00의 로컬 빌드·JVM 단위시험·린트·서명·정렬·내장 APK 동일성·소스/첨부 자료 점검 결과는 릴리즈에 첨부하는 V1.00-verification.json에 기록합니다. 새 기기 검사는 해당 JSON에서 실제 수행 여부를 구분합니다.

V1.00 실기 확인: 같은 RG477V8GB에서 v0.5.1을 삭제하지 않고 업데이트했습니다. 버전 화면과 기존 선택·클럭 요청·Custom 네 슬롯 보존을 확인했습니다. 별도 앱을 강제 종료한 뒤에도 Control Center의 요청 갱신과 설정 보존을 확인했습니다. 새 프로필 명령, WLE·배터리 부하 시험, 순정 복구, 물리 재부팅은 이번 시험에서 수행하지 않았습니다.

기존 v0.5.1 기록: RG477V8GB 한 대에서 APK 업데이트·순정 복구·명시 재설치·Custom4 보존·별도 앱 강제 종료 독립성·native 프로세스 재시작 후 OSD ON 보존을 확인했습니다. BAT의 실제 양수 충전/음수 방전과 제어된30·60·0FPS를 확인했습니다. JVM105개·린트 오류0을 통과했습니다. 이는 V1.00에서 같은 실기 시험을 모두 다시 수행했다는 뜻이 아닙니다.

기존 v0.5.0 기록: 순정 Control Center에서 첫 설치를 진행했고 재부팅 후 저장 요청 복원, 순정 복구 후 재부팅 시 순정 유지와 명시 재설치를 확인했습니다. 전체 공장초기화나 두 번째 기기 시험은 하지 않았습니다.

지속 클럭 상한, 보정된 절대 전력·효율, 모든 게임·기기·펌웨어 호환성, 전원 차단 중 설치는 미검증입니다. 자세한 내용은 [알려진 한계](LIMITATIONS.ko.md)를 참고하세요. 과거 원시 로그·개인 경로·실기 식별자는 공개 파일에 넣지 않습니다.
